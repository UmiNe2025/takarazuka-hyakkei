なぜ「定点観測」を始めるのか

宝塚市について書かれた情報は、公式サイト・観光ガイド・Wikipediaを含め、いずれも「今の情報」を提供します。しかし「同じ場所を、同じ形式で、長期間観測した記録」は、大規模メディアや行政サイトが構造的に持ちにくい情報です。当サイトは匿名個人の運営ですが、逆に「同一運営者が長期継続する」ことが唯一の強みになりえます。

この定点観測第1号を起点に、以下の観測点を反復していく予定です:

  • 宝塚百景100件のうち、代表的な10-20地点を年1-2回ペースで観測
  • 季節依存の景観(桜・梅・ダリア・紅葉・初詣)は該当時期に集中観測
  • 制度・情報の変化(市の窓口対応・料金改定・行事の日程変更)は判明次第記録

観測プロトコル(反復のための型)

今後の反復可能性のため、以下の型で継続します。この型は将来変更する場合、変更履歴を残します。

  1. URL命名規則: /observations/YYYY-MM-{地点名}.html
  2. 必須項目: 観測日 / 観測時期の説明(季節文脈) / SVG境内配置図 / 観測ノート(見た/読んだ/確認できた内容) / 前回観測との差分(2回目以降) / 参考情報源 / 次回観測予定時期
  3. SVG観測図の座標系: viewBox="0 0 800 500"、境内配置は北を上に統一、主要地点にラベル付与
  4. データセット構造化: 各観測ノートに Dataset schema(spatialCoverage / temporalCoverage / creator)を付与し、AI/学術利用に開放
  5. ライセンス: CC BY 4.0 相当(出典として「宝塚百景 / https://takarazuka.jun-nakatani.com/」明記)

観測ノート

季節文脈: 2026年7月

7月上旬の中山寺は、梅林の季節(3月上旬)からも、青龍塔の写真映えする桜/紅葉シーズンからも外れ、参拝者数は比較的落ち着く時期です。安産祈願の参拝は年間を通じて絶えず、戌の日(7月は9日・21日)や大安との重なりに混雑する構造は他月と同様。奥之院ハイキングは夏の暑さで健脚向け、雨天時は滑りやすさの注意が必要な時期にあたります。
