## 1. 「暮らしの便利帳」の標準的な作り方・構成(リサーチ)

- 多くの自治体版は **官民協働型**(例: 株式会社サイネックス「わが街事典」)。広告収入で自治体の費用負担ゼロ、住民・行政・地元事業者をつなぐ地域統合メディア。おおむね**2年に1度**改訂の保存版。
  - 出典: サイネックス https://www.scinex.co.jp/business/media/pppwork/ ／ 大阪市くらしの便利帳 https://www.city.osaka.lg.jp/seisakukikakushitsu/page/0000148414.html
- 構成は「**各種手続き・施設案内(行政情報)** + **地域情報(民間編集)**」。ライフイベント単位(出生・入学・引越・結婚・死亡など)で手続きを引ける形が主流。
- **近年の最重要トレンド = 「おくやみ(死亡・ご遺族の手続き)」の独立セクション化**。令和期に「おくやみコーナー/おくやみハンドブック」を設ける自治体が急増。
  - 標準構成: おくやみコーナー案内 / 手続きチェックリスト / 持ち物 / 市役所の手続き一覧(住民票・国保・後期高齢・年金・こども・障害・高齢・介護) / 市役所以外の手続き / 法定相続情報証明制度 / 委任状案内。
  - 出典例: 船橋市おくやみハンドブック https://www.city.funabashi.lg.jp/other/0001/frequent_okuyami_d/fil/okuyammihandobukku.pdf ／ おくやみ手続きナビ https://www.okuyaminavi.net/

## 実装手法メモ(次セッション用)
- guide.json は 2-space整形。**node スクリプトで JSON.parse→push→JSON.stringify(null,2)** が最も安全(手書きJSON構文エラー回避)。
- item schema: `title, important?(bool), summary, phone?, phoneNote?, url, urlLabel, tags[], sources[]`。カテゴリに `faq:[{q,a}]` も可。
- 追加後: `node tools/prerender.mjs && node tools/prerender-life.mjs && node tools/build-public.mjs` → 生成ページ grep 確認 → deploy → 本番確認 → git push。
- **新カテゴリ追加は color(--c-xxx)/icon() 依存で要CSS対応=リスク**。既存カテゴリへの項目追加を推奨。
